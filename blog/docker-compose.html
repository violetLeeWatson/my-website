本地启动docker-compose

June 22, 2026 · One min read

mysql 的yml：最终版本：

services:
  mysql:
    image: mysql:8.0
    container_name: mysql-db
    environment:
      MYSQL_ROOT_PASSWORD: admin
      MYSQL_DATABASE: parrot
    ports:
      - "3306:3306"
    volumes:
      - ./mysql/mysql_data:/var/lib/mysql
      - ./mysql/mysql_conf:/etc/mysql/conf.d
    networks:
      - mynet
networks:
  mynet:
    driver: bridge

镜像源，自己申请一个： 阿里云的镜像加速器申请地址：https://cr.console.aliyun.com/cn-hangzhou/instances/mirrors https://gxqnlnb4.mirror.aliyuncs.com

以后要起这个mysql服务就直接执行命令： docker-compose up -d 注意要在有yml文件的目录下（D:\0Study\docker\config）

停止使用yml启动的容器：等相关命令：

命令功能
docker-compose up启动服务
docker-compose up -d后台启动
docker-compose down停止并删除容器
docker-compose stop/start仅停止/启动容器
docker-compose -f custom.yml up指定非标准 compose 文件
