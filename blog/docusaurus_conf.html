逐项解释 docusaurus.config.ts 中的配置项

逐项解释 docusaurus.config.ts 中的配置项。

Config Overview

  • title: 网站主标题，显示在浏览器标签、导航栏等位置。
  • tagline: 站点副标题/口号，用于首页和社交分享卡文案。
  • favicon: 浏览器标签的小图标路径（通常放在 static 下）。
  • future.v4: 启用 Docusaurus v4 的未来兼容/实验性特性开关。
  • url: 网站的主域名（用于生成绝对链接和 Open Graph URL）。
  • baseUrl: 部署在域名下的子路径（例如 GitHub Pages 的仓库名，通常以 / 结尾）。
  • deploymentBranch: 部署时推送静态文件的分支（默认 gh-pages）；用于 GitHub Pages 部署。
  • trailingSlash: 是否在生成的 URL 末尾保留斜杠，false 常用于去掉末尾斜杠。
  • organizationName: GitHub 用户或组织名，常用于生成仓库相关链接与部署配置。
  • projectName: 仓库名，配合 organizationName 用于部署和生成某些自动链接。
  • onBrokenLinks: 断链处理策略（'throw'：构建失败；'warn'：仅提示）。
  • i18n.defaultLocale / i18n.locales: 默认语言与可用语言列表，影响 HTML lang、路径前缀和语言切换。
  • presets: 预设集合，这里用 'classic'，包含 docs、blog、theme 的默认配置和扩展点。
  • presets[classic].docs.sidebarPath: 指向侧边栏配置文件（侧边栏如何组织文档）。
  • presets[classic].docs.editUrl: “Edit this page” 链接前缀，建议改为你自己的仓库 URL 以启用编辑链接。
  • presets[classic].blog.showReadingTime: 是否在文章中显示预计阅读时间。
  • presets[classic].blog.feedOptions: 博客 feed（RSS/Atom）输出配置，例如生成哪些格式。
  • presets[classic].blog.onInlineTags / onInlineAuthors / onUntruncatedBlogPosts: 博客内容校验/策略（如发现问题时警告）。
  • presets[classic].theme.customCss: 自定义 CSS 路径，用于覆盖或补充默认样式。
  • themeConfig.image: 默认的社交分享/卡片图片（Open Graph/Twitter Card）。
  • themeConfig.colorMode.respectPrefersColorScheme: 是否尊重用户系统的深色/浅色主题偏好。
  • themeConfig.navbar: 导航栏设置（title、logo、items）。items 中可用 type: 'docSidebar'（链接文档侧边栏）、to（站内路由）、href（外部链接）等。
  • themeConfig.footer: 页脚配置（style、多列 links、版权文本等）。
  • themeConfig.prism.theme / darkTheme: 代码高亮主题，分别用于浅色与深色模式（这里使用 prism-react-renderer 的主题）。
  • TypeScript typings: 使用 Config 类型和 satisfies Preset.Options/ThemeConfig 只是为了编辑时的类型检查与自动完成，不改变运行时行为。
  • export default config: 导出配置对象，Docusaurus 在构建时读取它来生成站点。

逐项解释 docs/myname/category.json 中的配置项

下面是 category.json 各字段的简明解释及可选修改建议：

  • label: 在文档侧边栏中显示的分类名称（本例为 "Tutorial - Basics"）。
    建议：改为更贴合 docker 内容的名称，比如 "Docker 教程" 或 "Docker 入门"，以提高语义清晰度。

  • position: 在同级分类或侧边栏中排序的位置，数值越小越靠前（本例为 2）。
    建议：根据侧边栏中其它分类的 position 值调整顺序；如果不需要显式控制，可移除。

  • link: 定义当用户点击该分类时导航到的页面。常见 type 有 doc、generated-index 等。

    • type: "generated-index"：表示自动生成一个分类索引页面，列出该分类下的文档，并使用 description（下面字段）作为索引页说明。
    • description: 自动索引页上显示的一段描述文本（本例为 "5 minutes to learn..."）。
      建议：把 description 改为中文或更具体的介绍，例如 "本分类包含 Docker 基础教程与示例。"；如果你已有专门的入门文档文件，也可以用 type: "doc" 并设置 id 指向该文档。
